TAlpha v5.3 Overview

Purpose

TAlpha is an Android scientific application for calculating alpha-decay half-lives using semiempirical formulae by V. Yu. Denisov and co-authors.

TAlpha v5.3 retains the extended nuclear-data workflow introduced in v4.x and changes how the Android client handles large databases. The application no longer keeps the complete α-database in memory while the chart is open. A downloaded NDFS v3.0 package is installed as separate mass-number (A) layer files, and only the selected layer is loaded on demand.

The release also refines decay-scheme navigation, nuclide annotations and the presentation of calculated and experimental history data.

Main v5.3 capabilities

  • alpha-decay half-life calculation with two Denisov parameterizations;
  • manual entry of A, Z, Q_alpha, daughter excitation energy and l;
  • calculation history with save/load/delete;
  • Premium history sharing;
  • Premium personal logo;
  • Premium Chart of α-decaying nuclei;
  • mass-number Summary Scheme Index;
  • interactive isobaric nuclide charts;
  • pinch zoom and pan;
  • experimental ground-state alpha half-life display when available;
  • alpha-decay candidate schemes containing energetically accessible adopted daughter levels;
  • preservation and distinct display of experimentally observed ENSDF transitions;
  • SHORT and FULL RANGES decay-scheme views;
  • full schemes divided into selectable energy intervals of 20 levels;
  • less restrictive SHORT selection below 1 MeV (l_min <= 8, while the stricter l_min <= 1 rule remains above 1 MeV);
  • l_min information for potential transitions when supplied by NDFS v3.0;
  • transfer of a selected decay branch to the calculator;
  • NDFS v3.0-compatible candidate-level data while retaining v1/v2 fields;
  • automatic remote nuclear-database update;
  • streaming installation of a downloaded ZIP into separate A-layer files;
  • on-demand loading with only one selected layer retained in the ViewModel;
  • validation in a staging directory before a layered database becomes active;
  • fallback to the latest valid local database when remote update fails;
  • visible database/layer loading states and a RAM-use indicator;
  • improved navigation between the mass-number layer and decay scheme;
  • ground-state Jπ annotations when reliable data are available;
  • history display of experimental Jπ, level energy, branch Qα and T½exp;
  • fixed footer with application and α-DB versions plus the centered personal logo.

Nuclear-data workflow

The v5.3 user path is:

Chart of α-decaying nuclei
        ↓
Summary Scheme Index (select A)
        ↓
isobaric nuclide chart
        ↓
select parent nuclide
        ↓
alpha-decay scheme (SHORT or one FULL RANGES interval)
        ↓
select daughter level
        ↓
A, Z, branch Qα, Eexc and available l transferred to calculator
        ↓
calculate T1/2

Experimentally known transitions and potential adopted levels are complementary. If neither produces a usable level, the renderer falls back to a conventional ground-state-to-ground-state representation rather than crashing.

Network behavior

The half-life calculation itself is local.

Version 5.3 uses the network for services such as:

  • downloading the nuclear-database manifest and newer database package;
  • Google Play Billing;
  • Google Mobile Ads;
  • external links.

Once a valid nuclear database is present locally, the database subsystem is designed to continue using the latest local copy when a remote update cannot be obtained.

Memory model

The Summary Scheme Index is built from lightweight NuclideDatabaseInfo metadata: database version, format version and the list of available mass numbers. Selecting A starts an asynchronous layer read. Selecting another A cancels the previous request and releases the old layer reference. Consequently, chart memory scales primarily with one layer instead of the complete database.

Scientific-use notice

TAlpha combines model calculations, energetically allowed candidate levels and evaluated experimental data. A candidate level is not evidence of an observed branch, and a calculated half-life is not an experimental value.
