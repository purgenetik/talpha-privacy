TAlpha v3.0 Overview

Purpose

TAlpha is an Android scientific application for calculating alpha-decay half-lives using semiempirical formulae by V. Yu. Denisov and co-authors.

Version 3.0 extends the original calculator into an interactive nuclear-data tool. In addition to manual calculations, Premium users can browse a chart of known alpha-decaying nuclei, inspect experimental alpha-decay information imported from ENSDF, display known transitions to daughter excited states, and transfer a selected transition directly into the calculator.

Main v3.0 capabilities

  • alpha-decay half-life calculation with two Denisov parameterizations;
  • manual entry of A, Z, Q_alpha, daughter excitation energy and l;
  • calculation history with save/load/delete;
  • Premium history sharing;
  • Premium personal logo;
  • Premium Chart of α-decaying nuclei;
  • mass-number Summary Scheme Index;
  • interactive isobaric nuclide charts;
  • pinch zoom and pan;
  • experimental ground-state alpha half-life display when available;
  • known alpha-decay schemes to daughter excited levels;
  • transfer of a selected decay branch to the calculator;
  • NDFS v2.2-compatible Android-side data fields;
  • automatic remote nuclear-database update;
  • validation before installing a downloaded database;
  • fallback to the latest valid local database when remote update fails;
  • fixed footer with version information and centered personal logo.

Nuclear-data workflow

The v3.0 user path is:

Chart of α-decaying nuclei
        ↓
Summary Scheme Index (select A)
        ↓
isobaric nuclide chart
        ↓
select parent nuclide
        ↓
alpha-decay scheme
        ↓
select daughter level
        ↓
A, Z, branch Qα and Eexc transferred to calculator
        ↓
calculate T1/2

If ENSDF transition data are unavailable or cannot be interpreted, the decay-scheme renderer falls back to a conventional ground-state-to-ground-state representation rather than crashing.

Network behavior

The half-life calculation itself is local.

Version 3.0 uses the network for services such as:

  • downloading the nuclear-database manifest and newer database package;
  • Google Play Billing;
  • Google Mobile Ads;
  • external links.

Once a valid nuclear database is present locally, the database subsystem is designed to continue using the latest local copy when a remote update cannot be obtained.

Scientific-use notice

TAlpha combines model calculations and evaluated/imported nuclear data. A calculated half-life is a prediction of the implemented formula; an experimental value displayed from the database is a separate evaluated-data quantity. They should not be confused.
