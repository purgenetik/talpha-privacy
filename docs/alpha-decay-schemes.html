Alpha-decay Schemes

Purpose

AlphaDecayScheme.kt visualizes known alpha transitions from a selected parent nuclide to levels in the daughter nucleus.

Version 3.0 builds the scheme from the normalized alphaDecay object stored in the TAlpha nuclear database.

Data model

The renderer uses:

AlphaDecaySchemeData
 ├─ parentA, parentZ, parentSymbol
 ├─ daughterA, daughterZ, daughterSymbol
 ├─ qAlphaKeV
 └─ levels[]

Each AlphaDecayLevel can contain:

eExcKeV
spinParity
qAlphaKeV
tExpYears
l
intensityPercent

Parsing normalized ENSDF data

NuclideRecord.toAlphaDecaySchemeData() parses the stored alphaDecayJson.

It reads:

decays[]
transitions[]

The first available decay record is used to obtain daughter identification when present.

Dataset half-life mapping

For each normalized decay, the parser obtains:

dataset.id
halfLifeYears

and creates a map:

dataset ID → experimental half-life in years

A transition with the corresponding dataset ID can therefore carry the matched experimental lifetime into the displayed daughter level.

Daughter levels

A transition is only drawable as a daughter level when the parser can obtain:

finalLevel.energy.value

Invalid or negative excitation energies are skipped.

Spin/parity is read from the final level when available. Intensity is read from the transition intensity object when available.

Branch Qα

The database qAlpha is the parent ground-state-to-ground-state value.

For a level at excitation energy Eexc the displayed/transferred branch value is:

Qα(branch) = Qα(g.s.→g.s.) - Eexc

with both terms in keV inside the scheme model.

Duplicate levels

Multiple ENSDF datasets may contain transitions to the same daughter excitation energy.

Version 3.0 groups levels using excitation energy formatted to three decimal places. When duplicates exist, it prefers an entry that contains an experimental lifetime; otherwise the first matching entry is used.

The resulting levels are sorted by excitation energy.

Fallback behavior

If:

  • alphaDecay is absent;
  • JSON parsing fails;
  • the normalized structure is unexpected;

TAlpha creates a conventional parent-to-daughter scheme with no imported excited-level list.

The interactive renderer can then represent the ground-state branch instead of crashing.

Interaction

The scheme supports zoom/pan and clickable daughter levels.

Selecting a level creates:

AlphaDecaySelection

containing:

parent A
parent Z
branch Qα in MeV
daughter excitation energy in MeV
experimental half-life when available

The calculator then receives these values.

Orbital angular momentum

The v3.0 ENSDF-to-scheme parser currently assigns:

l = 0

to imported transitions. The main activity also sets the calculator l field to 0 after a scheme selection.

Therefore, for a transition requiring non-zero angular momentum, the user must enter the physically appropriate l manually before calculation.
