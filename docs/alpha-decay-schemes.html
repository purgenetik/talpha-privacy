Alpha-decay Schemes

Purpose

AlphaDecayScheme.kt visualizes energetically accessible alpha-decay channels from a selected parent nuclide to levels in the daughter nucleus.

Version 5.3 combines two complementary NDFS v3.0 sources:

  • alphaDecay.transitions — experimentally observed/evaluated alpha transitions;
  • adoptedLevels — daughter levels that can potentially be populated according to the candidate-generation policy.

The presence of a level in adoptedLevels does not mean that the corresponding alpha branch has been observed experimentally.

Data model

The renderer uses:

AlphaDecaySchemeData
 ├─ parentA, parentZ, parentSymbol
 ├─ daughterA, daughterZ, daughterSymbol
 ├─ qAlphaKeV
 └─ levels[]

Each AlphaDecayLevel can contain:

eExcKeV
spinParity
qAlphaKeV
tExpYears
l
intensityPercent
experimental

The experimental flag distinguishes measured/evaluated transitions from potential adopted levels.

Parsing experimental transitions

NuclideRecord.toAlphaDecaySchemeData() parses the stored alphaDecayJson and adoptedLevelsJson belonging to the selected A layer.

It reads:

decays[]
transitions[]

The first available decay record is used to obtain daughter identification when present.

Dataset half-life mapping

For each normalized decay, the parser obtains:

dataset.id
halfLifeYears

and creates a map:

dataset ID → experimental half-life in years

A transition with the corresponding dataset ID can therefore carry the matched experimental lifetime into the displayed daughter level.

Daughter levels

A transition is only drawable as a daughter level when the parser can obtain:

finalLevel.energy.value

Invalid or negative excitation energies are skipped.

Spin/parity is read from the final level when available. Intensity is read from the transition intensity object when available.

Parsing potential adopted levels

The converter also reads the serialized adoptedLevelsJson. For each usable level it obtains:

energy.value
spinParity.stringRepresentation
l_min

Invalid or negative energies are skipped. If l_min cannot be established reliably, the UI omits a derived angular-momentum annotation rather than inventing a physical value.

An adopted level is not added a second time when an experimental level has the same spin/parity and an excitation energy within 1 keV.

Branch Qα

The database qAlpha is the parent ground-state-to-ground-state value.

For a level at excitation energy Eexc the displayed/transferred branch value is:

Qα(branch) = Qα(g.s.→g.s.) - Eexc

with both terms in keV inside the scheme model.

Duplicate levels

Multiple ENSDF datasets may contain transitions to the same daughter excitation energy.

Experimental levels are grouped using excitation energy formatted to three decimal places. When duplicates exist, the renderer prefers an entry that contains an experimental lifetime; otherwise it uses the first matching entry.

The resulting levels are sorted by excitation energy.

SHORT and FULL RANGES views

The scheme can be shown in SHORT mode:

  • all experimental levels are always included;
  • adopted levels below 1 MeV may satisfy the relaxed l_min <= 8 condition;
  • above 1 MeV the stricter l_min <= 1 condition remains;
  • potential levels fill the remaining places up to a nominal total of 10 levels;
  • if 10 or more experimental levels exist, no potential levels are added in SHORT mode.

The former single LONG canvas is replaced by FULL RANGES (keV). The complete sorted level set is divided into intervals containing 20 levels each. Double-arrow buttons select neighboring intervals; a diamond marks the active interval and the displayed boundary energies identify it. This keeps large schemes readable without removing levels from the full set.

The navigation controls remain above the scheme. 2SHORT switches to the compact view, 2CHART returns to the selected A-layer chart, and CANCEL returns directly to the calculator.

Thin arrows are drawn only for experimental transitions. Potential levels remain selectable and are shown without an experimental-transition arrow.

Fallback behavior

If:

  • alphaDecay is absent;
  • JSON parsing fails;
  • the normalized structure is unexpected;

TAlpha creates a conventional parent-to-daughter scheme with no imported excited-level list.

The interactive renderer can then represent the ground-state branch instead of crashing.

Interaction

The scheme supports zoom/pan and clickable daughter levels.

Selecting a level creates:

AlphaDecaySelection

containing:

parent A
parent Z
branch Qα in MeV
daughter excitation energy in MeV
experimental half-life when available
orbital angular momentum from the selected level

The calculator then receives these values. Selecting a level returns to the calculator with the branch data; 2CHART returns to the current isobaric layer without changing the calculator.

Orbital angular momentum

Potential adopted levels use l_min when it can be determined from sufficiently definite parent/daughter Jπ. The l label is omitted when the assignment is unknown or ambiguous rather than inventing a value.

The user remains responsible for checking and, when necessary, editing l before calculation.
