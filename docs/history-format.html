Calculation History Format

File type

TAlpha calculation histories use:

.talpha

The active file is stored under:

filesDir/data/default.talpha

Header

A,Z,Q_alpha,E_exc_level,l,logT_2009,Tsec_2009,Tyr_2009,logT_2015,Tsec_2015,Tyr_2015

Columns

ColumnMeaning
AParent mass number
ZParent atomic number
Q_alphaInput Qα
E_exc_levelDaughter excitation energy
lOrbital angular momentum
logT_20092009/2010 log10 half-life
Tsec_20092009/2010 half-life, seconds
Tyr_20092009/2010 half-life, years
logT_20152015 log10 half-life
Tsec_20152015 half-life, seconds
Tyr_20152015 half-life, years

Duplicate detection

The five calculator inputs define duplicate identity. Floating Qα and excitation values are compared with the tolerance implemented in HistoryStorage.kt.

Saved histories

Saved names are sanitized, receive the .talpha extension when needed, and cannot use the reserved active name default.talpha.

Important distinction

.talpha history files are unrelated to the JSON TAlpha NDFS nuclear database. History records contain calculations; NDFS contains nuclear-data records for chart/database functionality.
