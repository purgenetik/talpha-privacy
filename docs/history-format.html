Calculation History Format

File type

TAlpha calculation histories use:

.talpha

The active file is stored under:

filesDir/data/default.talpha

Header

A,Z,Q_alpha,E_exc_level,l,logT_2009,Tsec_2009,Tyr_2009,logT_2015,Tsec_2015,Tyr_2015,q_exp,Elevel_exp,T_exp

Columns

Column Meaning
A Parent mass number
Z Parent atomic number
Q_alpha Input Qα
E_exc_level Daughter excitation energy
l Orbital angular momentum
logT_2009 2009/2010 log10 half-life
Tsec_2009 2009/2010 half-life, seconds
Tyr_2009 2009/2010 half-life, years
logT_2015 2015 log10 half-life
Tsec_2015 2015 half-life, seconds
Tyr_2015 2015 half-life, years
q_exp Selected experimental branch Qα, when available
Elevel_exp Selected experimental daughter-level energy, when available
T_exp Experimental half-life in years, when available

The final three fields are optional. The reader remains compatible with the earlier 11-column format.

Duplicate detection

The five calculator inputs define duplicate identity. Floating Qα and excitation values are compared with the tolerance implemented in HistoryStorage.kt.

Saved histories

Saved names are sanitized, receive the .talpha extension when needed, and cannot use the reserved active name default.talpha.

Individual saved files can be deleted from the load dialog. Premium users choose a specific history file and share its existing contents through Android's standard sharing interface.

Important distinction

.talpha history files are unrelated to the JSON TAlpha NDFS nuclear database. History records contain calculations; NDFS contains nuclear-data records for chart/database functionality.
