User Guide

1. Calculator

Enter:

A
Z
Q_alpha [MeV]
E_exc_level [MeV]
l

TAlpha calculates the half-life with both implemented parameterizations:

  • PRC 79 (2009) + Erratum (2010);
  • PRC 92 (2015).

The application derives N = A - Z and selects the appropriate fitted coefficient set automatically.

2. Results

The calculation engine produces for each model:

  • corrected decay energy;
  • log10(T1/2 [s]);
  • T1/2 in seconds;
  • T1/2 in years.

The main UI presents the calculated lifetime results; internal corrected-Q values remain part of the calculation result object.

3. Calculation history

Successful calculations can be stored in the active history file:

filesDir/data/default.talpha

History can be viewed, saved under another .talpha filename, loaded, and deleted. Premium users can share history through Android's standard sharing interface.

See History Format.

4. Chart of α-decaying nuclei

The navigation drawer contains Chart of α-decaying nuclei. In v4.0 this is a Premium feature.

Opening it displays the Summary Scheme Index, generated from the mass-number layers available in the currently loaded nuclear database.

Select an entry such as:

A=152

to open that isobaric layer.

5. Isobaric chart

The chart plots nuclides belonging to one mass number A.

The vertical coordinate is derived from mass excess relative to the minimum mass excess in the selected layer. Neighboring Z values are connected graphically.

For each nuclide the chart can display:

  • nuclide label;
  • Qα in keV when supplied;
  • experimental alpha half-life T½ in years when T_hl_exp is present.

The chart supports:

  • pinch-to-zoom;
  • pan;
  • tap selection.

Clickable regions are outlined to make interactive areas visible.

6. Alpha-decay scheme

Tapping a nuclide opens its alpha-decay scheme.

TAlpha combines experimentally known ENSDF transitions with energetically accessible adopted daughter levels from NDFS v3.0. Experimental data are preserved and visually distinguished; a potential adopted level does not by itself indicate an observed alpha branch.

For a displayed branch:

branch Qα = parent ground-state Qα - daughter excitation energy

The scheme may include:

  • daughter excitation energy;
  • spin/parity when available;
  • branch Qα;
  • experimental half-life associated with the matched decay dataset;
  • transition intensity when available in the imported record;
  • minimum orbital angular momentum l_min for a potential level when available.

Duplicate experimental daughter levels from multiple ENSDF datasets are merged by excitation energy for display, with preference for a record carrying an experimental lifetime. A potential level matching an experimental level within 1 keV and with the same spin/parity is not added again.

The scheme initially opens in SHORT mode. It always contains all experimental levels and may add low-l potential levels (l <= 1) up to a nominal total of 10. Tap LONG to display all available potential and experimental levels. Thin arrows identify experimental transitions.

7. Selecting a decay branch

Tap a daughter level to transfer the branch to the calculator.

The source transfers:

A      = parent A
Z      = parent Z
Qalpha = selected branch Qα / 1000 [MeV]
Eexc   = selected daughter excitation / 1000 [MeV]
l      = transition value or l_min; 0 when unavailable

Experimental transition records currently use l = 0. Potential adopted levels use l_min when available and otherwise fall back to 0. The user can edit l manually before calculating.

After selection, the decay scheme and nuclide chart close and the calculator is shown with the transferred values.

8. Missing level data

If neither experimental transitions nor potential adopted levels can be parsed into usable daughter levels, TAlpha generates a conventional ground-state scheme instead of terminating the chart.

9. Database loading

At application startup, TAlpha attempts to obtain the best available nuclear database. The application first knows the latest local version, then attempts a remote manifest/update, and finally loads the latest local database.

If no database can be loaded, the Chart screen reports:

Nuclide database is not available.

10. Footer

Version 4.0 contains a fixed footer.

It shows the application version and currently loaded α-DB version on the left. A Premium personal logo, when installed, is displayed in the exact center of the footer. The standard TAlpha logo remains in the application header.
