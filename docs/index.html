TAlpha v5.3 Documentation

Technical and user documentation for TAlpha v5.3, an Android application for alpha-decay half-life calculations and exploration of potential and experimentally evaluated alpha-decay channels.

This is documentation revision 5.3, covering the 5.0 feature line and the subsequent 5.x presentation refinements. The supplied source snapshot declares versionCode = 27 and versionName = "5.0"; the documentation revision is intentionally newer than that internal source label.

Controlled specification

The formal TAlpha Nuclide Database Format Specification (NDFS) v3.0 is maintained separately. This documentation explains how the Android application uses NDFS but does not duplicate or redefine the specification.

Source of truth

For application behavior, the tagged Kotlin source is authoritative. For the nuclear database schema, use the formal NDFS specification. For the half-life models, consult and cite the original scientific publications.
