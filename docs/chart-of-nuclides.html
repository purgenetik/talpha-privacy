Chart of α-decaying nuclei

Purpose

The v5.3 chart provides graphical navigation through potential alpha-decaying nuclei stored in the TAlpha nuclear database. The candidate set is not limited to nuclides with experimentally observed transitions; experimental annotations are retained when available.

The feature is Premium-gated in MainActivity.kt.

Summary Scheme Index

NuclideSummary.kt receives the list of mass numbers from:

NuclideDatabaseInfo.layerMassNumbers

It removes duplicates, sorts the values, and displays them in a four-column scrollable index:

A=151   A=152   A=153   ...

Selecting a mass number starts an asynchronous read of the corresponding DB_vN_A.json. Only that NuclideLayer is kept in memory; selecting a different A releases the previous layer and cancels an obsolete request.

CANCEL returns to the calculator.

Isobaric layer

NuclideChart.kt displays all NuclideRecord entries belonging to one mass number.

The chart uses:

  • Z as the horizontal nuclear coordinate;
  • mass excess relative to the layer minimum as the vertical-energy coordinate.

Conceptually:

Erelative = massExcess(A,Z) - min(massExcess for layer A)

Neighboring nuclides ordered by Z are connected by light lines.

Nuclide annotation

A plotted nuclide may show:

  • nuclide notation;
  • Qα=... keV;
  • T½=... y when T_hl_exp is available.
  • ground-state spin/parity Jπ when it can be obtained reliably.

The selected nuclide is highlighted.

Interaction

The Canvas supports:

  • transform gestures;
  • pinch zoom;
  • pan;
  • tap detection.

Scale is constrained by renderer constants, and the point under the user's fingers is kept stable during zoom.

The renderer constructs hit boxes around labels and associated information. Visible outlined clickable regions indicate where tapping will open a nuclide.

Selecting a nuclide

onNuclideClick converts the selected NuclideRecord into:

AlphaDecaySchemeData

using:

nuclide.toAlphaDecaySchemeData()

and opens the interactive alpha-decay scheme.

2CHART in the decay scheme returns to the currently selected mass-number layer. CANCEL returns to the calculator. Selecting a daughter level closes the chart and returns to the calculator with the chosen values.

Ground-state spin/parity

The chart/scheme logic searches the available normalized decay records for a usable ground-state Jπ rather than relying on only the first record. For an even-even ground state, the conventional 0+ fallback may be used. Retrieved values are cached for drawing so JSON parsing is not repeated for every label on every recomposition.

Experimental half-life

The chart reads:

NuclideRecord.tHalfExpYears

which is populated from the optional NDFS field:

T_hl_exp

Only finite positive values are displayed.

Missing Qα

The database parser preserves the NDFS convention for qAlpha; the chart formatter only prints a meaningful positive finite Qα value as a normal numeric annotation. Schema semantics remain defined by the formal NDFS specification.
