Building TAlpha v3.0 from Source

Requirements

  • Android Studio compatible with the project Gradle configuration;
  • Android SDK / compile target required by the project;
  • JDK 17;
  • Git for repository workflows;
  • Android device or emulator.

The supplied build declares:

minSdk = 24
targetSdk = 37
versionCode = 18
versionName = 3.0

Clone

git clone git@github.com:purgenetik/TAlpha4.git
cd TAlpha4

Open the directory containing:

settings.gradle.kts
build.gradle.kts
gradlew
app/

in Android Studio and allow Gradle synchronization to finish.

JDK

Use JDK 17 for Gradle/Kotlin compilation according to the project configuration.

Debug build

Windows:

.\gradlew.bat assembleDebug

Linux/macOS:

./gradlew assembleDebug

Release bundle

For Google Play, build a signed Android App Bundle from Android Studio or the project's configured release workflow.

Before publishing a new release, increment versionCode. Google Play will not accept reuse of a previously uploaded version code.

Release testing

Test the release/minified build, not only debug. TAlpha previously required an R8-related release fix, so optimized-build testing is part of the release checklist.

For v3.0 additionally test:

  • database download/update;
  • startup with network unavailable after a database has been installed;
  • Summary Scheme Index;
  • several isobaric layers;
  • zoom/pan and hit zones;
  • ENSDF-derived alpha-decay schemes;
  • transfer from a daughter level to calculator;
  • Premium gating;
  • footer and personal logo.

Source release

Prefer Git tags for reproducible source snapshots:

v3.0

A GitHub source archive generated from the release tag is preferable to manually copying an Android Studio working directory.
