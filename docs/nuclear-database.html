TAlpha Nuclear Database

Specification

The formal schema is defined by the separately maintained TAlpha Nuclide Database Format Specification (NDFS). Version 3.0 of the Android application reads the v1 core fields plus v2.2 additions used for experimental alpha-decay information.

See Specifications.

Kotlin data model

NuclideDatabase.kt defines:

NuclideDatabase
 ├─ versionCode
 ├─ formatVersion
 └─ layers[]

NuclideLayer
 ├─ a
 └─ nuclides[]

NuclideRecord
 ├─ a
 ├─ z
 ├─ symbol
 ├─ massExcess
 ├─ qAlpha
 ├─ estimated
 ├─ tHalfExpYears
 ├─ alphaDecayJson
 └─ rawJson

Parsed JSON fields

The Android parser requires the v1 core:

versionCode
layers
layers[].A
layers[].nuclides
Z
symbol
massExcess
qAlpha
estimated

It additionally reads:

formatVersion
T_hl_exp
alphaDecay

T_hl_exp is accepted only when it is finite and greater than zero.

The complete original nuclide JSON object is also retained as rawJson.

JSON and ZIP support

The local loader accepts files named as versioned TAlpha databases and supports:

talpha_nuclides_<version>.json
talpha_nuclides_<version>.zip

For a ZIP package, the loader scans entries until it finds a non-directory .json entry and parses that content.

Local storage

The database directory is:

filesDir/nuclide_database/

The application determines the latest local database by extracting the numeric version from matching JSON/ZIP filenames and selecting the greatest version.

Basic parser validation

After parsing, the Android code requires:

versionCode > 0
layers is not empty

The updater additionally verifies that a newly downloaded database's internal versionCode equals the manifest's latestVersion.

The formal NDFS document defines the broader schema and physical-consistency rules; this page only describes checks implemented by the Android reader.

Compatibility

formatVersion is optional in the Android data model. Optional v2.2 fields may be absent. This permits the reader to retain compatibility with records that only contain the earlier core fields, provided the required parser fields are present.
