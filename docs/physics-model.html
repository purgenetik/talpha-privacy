Physics Model

Implemented references

TAlpha implements alpha-decay half-life parameterizations based on:

  1. V. Yu. Denisov and A. A. Khudenko, Physical Review C 79 (2009), 054614.
  2. Erratum, Physical Review C 82 (2010), 059901.
  3. V. Yu. Denisov, O. I. Davidovskaya and I. Yu. Sedykh, Physical Review C 92 (2015), 014602.

For derivation, fit quality and applicability, consult the original publications.

Variables

  • A — parent mass number;
  • Z — parent proton number;
  • N = A - Z;
  • Q — input alpha-decay energy in MeV;
  • Eexc — daughter excitation energy in MeV;
  • l — orbital angular momentum.

Both routines calculate a corrected energy and then evaluate a fitted expression for:

[ \log_{10}(T_{1/2}/\mathrm{s}). ]

2009/2010 implementation

For Z < 60:

[ r_k=13.6\times10^{-6},\quad \epsilon=2.408. ]

For Z >= 60:

[ r_k=8.7\times10^{-6},\quad \epsilon=2.517. ]

The source calculates:

[ Q_1=Q-E_{exc}+r_k[Z^\epsilon-(Z-2)^\epsilon]. ]

Then:

[ r_\mu=\left(\frac{A}{A-4}\right)^{1/6} ]

and

[ \log T= a+b\frac{A^{1/6}\sqrt{Z}}{r_\mu} +c\frac{Z}{\sqrt{Q_1}} +d\frac{\sqrt{l(l+1)}A^{1/6}}{Q_1} +e x_e. ]

x_e = 0 for even l and x_e = -2 for odd l.

2015 implementation

The source computes electronic binding-energy terms:

[ BE(Z)=\left(14.4381Z^{2.39}+1.55468\times10^{-6}Z^{5.35}\right)10^{-6} ]

and uses:

[ Q_1=Q-E_{exc}+BE(Z)-[BE(Z-2)+BE(2)]. ]

The half-life expression is:

[ \log T= a+b(A-4)^{1/6}\sqrt{Z} +c\frac{Z}{\sqrt{Q_1}} +d\frac{\sqrt{l(l+1)}A^{1/6}}{Q_1} +e x_e. ]

Numerical validity

Both calculator routines require the corrected energy to be positive. A numerical result should not be interpreted as proof that the chosen semiempirical parameterization is physically applicable to every possible manually entered combination.

Experimental versus calculated lifetime

Version 4.0 can display T_hl_exp from the nuclear database. This experimental/evaluated value is not used as the calculated result and should be distinguished from the half-life predicted by the Denisov formulas. Likewise, an NDFS v3.0 potential adopted level indicates energetic accessibility, not an experimentally measured lifetime.
