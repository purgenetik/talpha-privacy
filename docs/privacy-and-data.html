Privacy and Data Handling

This page documents behavior visible in the v4.0 source. It is not a legal replacement for the published Privacy Policy.

Local calculation

The Denisov half-life calculations run locally.

Calculation history

History is stored in the application's private files area under:

filesDir/data/

Nuclear database

Downloaded TAlpha nuclear databases are stored locally under:

filesDir/nuclide_database/

The application contacts the configured remote source to retrieve the database manifest and, when a newer version exists, the database package.

The Android application consumes prebuilt TAlpha data; it does not directly query ENSDF for each user interaction.

Personal logo

A Premium personal logo is stored locally as:

personal_logo.png

Sharing

Premium history sharing passes a generated file to Android's share system. After the user selects another application, handling by that destination is governed by the destination application's policies.

Advertising

The Free version integrates Google Mobile Ads / AdMob.

Purchases

Premium purchases use Google Play Billing. TAlpha receives purchase/product state needed for entitlement; payment processing is performed by Google Play.

External links

External links are opened using Android/browser facilities.

Maintenance

The public Privacy Policy should be reviewed whenever the project changes:

  • advertising SDKs;
  • billing behavior;
  • database hosting;
  • analytics/crash reporting;
  • cloud storage;
  • user accounts;
  • third-party services.
