Current nuclear-database specification

TAlpha NDFS v3.0 — TAlpha Nuclide Database Format Specification

TAlphaNDFS_spec_v.3.0.pdf

NDFS v3.0 is an additive extension of v2.2. It introduces adoptedLevels for energetically accessible daughter-level candidates while preserving experimental transitions in alphaDecay.transitions.

The v5.3 DB_vN/DB_vN_A.json layout is an internal Android installation format. It does not supersede or revise NDFS v3.0.

For reproducibility, the previous specification remains available:

TAlphaNDFS_spec_v.2.2.pdf

Documentation policy

General documentation explains how TAlpha uses the database, but the formal specification remains authoritative for:

  • schema fields and types;
  • canonical units;
  • compatibility rules;
  • optional/required fields;
  • ENSDF provenance;
  • validation rules;
  • archival interchange format;
  • database-generation pipeline requirements.

Do not copy the full specification into ordinary Markdown documentation. Link to the controlled PDF so that schema rules have one authoritative definition.

Future versions

When NDFS is revised, retain older specification files needed for reproducibility and add a new explicitly versioned PDF rather than silently replacing the previous document.
